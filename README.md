# KiksOpti

Optimisation PC pour le gaming, pour Windows 10 et 11.

## Télécharger

**[⬇ Télécharger KiksOpti.exe (dernière version)](https://github.com/nnaillyk/kiksopti/releases/latest/download/KiksOpti.exe)**

Toutes les versions et leurs nouveautés : [Releases](https://github.com/nnaillyk/kiksopti/releases)

- Un seul fichier, rien à installer. Double-cliquez dessus et acceptez la demande d'autorisation administrateur.
- Si Windows affiche « Windows a protégé votre ordinateur » : *Informations complémentaires* › *Exécuter quand même* (le fichier n'est pas signé par un certificat payant).
- Pour vérifier le fichier : son empreinte SHA-256 est publiée à côté (`KiksOpti.exe.sha256`).

## Mettre à jour

Dans KiksOpti, cliquez sur **Rechercher une mise à jour** (en bas à gauche). L'app télécharge la nouvelle version, vérifie son empreinte, puis redémarre. Vos réglages et leurs sauvegardes sont conservés.

## Sécurité

Rien n'est activé par défaut. Un point de restauration Windows est créé avant la première modification, chaque réglage peut être annulé un par un, et le bouton « Tout restaurer » remet le PC dans son état initial.
